# 2026-10-21 初始实现

## 日期

2026-10-21

## 原因

建立 Vue + Rust 直播状态粉丝站的初始版本，统一前端展示、B 站接口代理、缓存降级、版本管理和一键更新启动流程。

## 涉及模块与文件

- 前端：Vue 页面与本地优化后的图片资源。
- 后端：Rust HTTP 服务、B 站公开接口代理、健康检查和版本接口。
- 启动：`scripts/update-start.sh`，默认端口 `2993`。
- 文档：
  - `docs/architecture/overview.md`
  - `docs/features/fan-site.md`
  - `docs/api/live-status.md`
  - `docs/changes/2026-10-21-initial-implementation.md`
  - `README.md`
- 版本：`VERSION`（`1.0.0`）。

## 设计决策

- 采用 Rust 作为单一入口，静态托管 `dist/` 并代理 `/api/live-status`，避免浏览器跨域和上游限流问题。
- B 站接口字段通过后端归一化；成功缓存 20 秒，失败退避时使用上次快照，完全无快照时返回可读错误。
- 图标先从图床下载，再用本地工具压缩优化并提交仓库，运行时不依赖图床。
- 更新脚本只负责更新、构建和启动，不执行 Git 提交、推送或其他不可逆操作。

## 验证要求

- 访问 `http://127.0.0.1:2993/` 检查页面、状态文案和媒体资源。
- 调用 `/healthz`、`/api/version` 和 `/api/live-status?uid=85996232&room_id=1890510937`，确认信封、字段类型和降级行为。
- 在 B 站接口超时或返回异常时，确认前端保留快照并显示延迟/错误提示。
