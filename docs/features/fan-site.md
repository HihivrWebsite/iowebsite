# 粉丝站点功能

## 功能范围

- 展示主播头像、昵称、直播间标题、分区和在线/关注数据。
- 显示直播状态：`0=未开播`、`1=直播中`、`2=轮播`，并提供可读的中文文案。
- 直播中时展示开播时间与已持续时长；未开播或轮播时展示合适的空状态。
- 展示直播间封面和关键帧；图片使用仓库内本地优化资源或经过服务端代理的公开 URL。
- 页面自动刷新直播状态，展示最近更新时间，避免用户把旧缓存误认为实时状态。
- 上游暂时不可用时使用上次成功快照继续展示，并明确标记“数据可能延迟”；没有快照时显示可重试错误。

## 资源处理

图标和图片素材遵循“下载、优化、入库”流程：从指定图床下载原图后，使用本地压缩工具生成适合 Web 的尺寸，再放入前端资源目录。运行时不依赖图床可用性，也不在浏览器端执行远程图片转码。

## 交互约定

- 页面首屏应优先呈现直播状态和标题，媒体资源加载失败不应阻塞核心信息。
- 手机和桌面布局均支持，按钮和链接具有清晰焦点状态。
- 页面使用后端 `/api/live-status` 的统一信封，不直接访问 B 站接口，避免跨域、限流和字段变化扩散到前端。

## 非目标（1.0.0）

- 用户登录、Cookie 注入、弹幕互动、付费或通知功能不在本期范围。
- 不在前端直接实现 B 站接口缓存；缓存和退避由 Rust 服务统一处理。
